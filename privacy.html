When you use "Pay with Pi" we collect: Pi username (for booking), WhatsApp number (for invoice), route From/To, date. No sensitive personal data is stored. 4. Pi Network Payments

All payments are 100% in Pi. We use Pi SDK 2.0 with server approval. Payment flow: onReadyForServerApproval → fetch /api/approve → onReadyForServerCompletion → fetch /api/complete → BOOKED!
