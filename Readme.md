## Utility
Real bus ticket booking in Johannesburg - Soweto, Pretoria, Durban routes. Tickets paid in Pi Mainnet. This app is the TRANSPORT layer for the ecosystem:

- Marble Floors workers use this bus to get to installation sites
- Agri Equipment Market customers use this bus to come buy tools
- Logistics uses bus cargo for small parcel delivery

## Sequence in Ecosystem
`Gauteng Hub -> Marble order -> Building needs workers -> Auto-books 3 seats on Revelation Bus (0.2 Pi each) -> Pi payment`

## Pi Integration
- Pi Login shared via ecosystem.js
- Pi Payments: Ticket = 0.1 to 0.5 Pi depending on distance
- Mainnet: Pi.init sandbox:false
